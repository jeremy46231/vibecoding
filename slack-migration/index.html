🔬 Prediction Methods Explained

Upstream Prediction

The prediction provided by the original tracking source.

Overall Rate

Calculates the average rate from the beginning of tracking to now, then extrapolates to 100%.

Last 20 Minutes

Uses only the most recent 20 minutes of data to capture the current pace of migration.

Last Hour

Uses the last hour of data for a more stable but still recent prediction.

Weighted Average

Gives more weight to recent data points while still considering historical trends.

Linear Regression

Fits a line through recent data points using least squares regression.
